# FISTAGENT

Independent fair-mint token on BNB Smart Chain for Binance Agentic Wallets holding a `.ai` Agent ID.
**Not affiliated with Binance. No promise of profit. Not deployed yet; not audited.**

FISTAGENT = BNAGENT v2 with one change: **after the pool opens at share 10,000, 100% of each mint payment goes to the treasury** (BNAGENT added 80% to the pool). Before share 10,000: 20% treasury / 80% parked for the pool, unchanged. See docs/JAGER-DIFF.md (top).

- `src/` — `FistagentMint.sol` (Jager-model mint: 1,100 burned shares, pricing, quotas, 20% treasury / 80% parked until share 10,000, automatic pool open at share 10,000 with LP to dead, then 100% of each mint to the treasury, floor line, tax conversion, admin/renounce, 30-day `withdrawUnfilled()`: after day 30 without share 10,000 the treasury can withdraw the parked 80% repeatedly while minting continues) and `FistagentToken.sol` (BEP-20 with transfer rules and taxes).
- `test/FistagentFork.t.sol` — BSC mainnet fork tests (deploys through the real CREATE2 proxy, real Agent ID holders, Chainlink, PancakeSwap).
- `script/` — mainnet wiring (`BscConfig.sol`) and the unsigned plan generator (`BuildPlan.s.sol`).
- `deploy/bsc-mainnet-plan.json` — unsigned deployment calldata. Nothing has been broadcast.
- `site/` — static website, planned at https://fistagent.onrender.com/ (NOT created/published yet); `site/llms.txt`, `site/agent.md`. Logo (traced from the user's reference: gold circle, white glyph), favicons, lockup and og image generated by `tools/make_logo_fist.py`.
- `server/` — Binance Agentic Wallet QR-login proxy (Node, no deps), planned Render web service `fistagent-api` (not created). Env `ALLOW_TO` = mint contract address after deployment.
- `docs/PARAMETERS.md` — every parameter and the scaling math. `docs/DEPLOY.md` — deployment steps. `docs/JAGER-DIFF.md` — audit against the Jager reference.
- `test/local-fork/deploy-local.sh` — replays the plan on a local anvil fork (never mainnet) for API tests.
